
# Krokedils kunskapsbank

Ett WordPress-plugin som hanterar och visar vanliga supportärenden och deras lösningar.

## Vad pluginet gör

Skapar en post-typ **Supportärende** där man kan dokumentera vanliga kundproblem och hur de löses. Varje ärende kan kategoriseras med taxonomin "Supportkategori". Det har även funktion för att automatiskt skriva om permalänkar vid aktivering.

## Post-typ

Pluginet registrerar post-typen "Supportärende" där alla supportärenden finns, man kan även lägga till ett nytt supportärende, redigera supportärende eller söka efter ett eller flera supportärende

## Taxonomier

Taxonomiet som registreras heter "Supportkategorier" och är en hierarkisk taxonomi med supportkategorier som t.ex Klarna, Walley, Nexi, som alla är olika kategorier och baseras på kundens namn

## Installation
Det installeras genom:
1.  ```git clone https://github.com/thyranystrom/kroke ```
2. Aktivera pluginet i WordPress under **Tillägg-> Installerade tillägg**
